## Initial clean source preparation

OpenITSM provides IT assets/services, ticket/task workflows, organization scope, workspace/chat, notifications, audit and scoped reporting.

The initial repository imports only the allowlisted clean source candidate and English community documentation. It uses Apache-2.0 with Copyright 2026 Roland Cobi, exact Windows/Python dependency locks, retained security regressions and a fresh Git history.

OpenITSM-rc-001 remains the separate immutable validated ZIP. The GitHub source tree contains additional documentation and is not byte-identical to that ZIP. No stable release, tag, publication, deployment or independent security certification has occurred as part of preparation.
