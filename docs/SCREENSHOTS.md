# Screenshots

These are unmodified browser screenshots of OpenITSM's English interface, captured in Chrome at a 1600 x 1100 viewport using the dark theme.

| Image | View |
| --- | --- |
| [Dashboard](images/dashboard.png) | Service operations, ticket counts, charts and SLA indicators |
| [Assets](images/assets.png) | CMDB inventory, owners and service associations |
| [Ticket workflow](images/ticket-workflow.png) | Ticket details, timeline, assignment and workflow signatures |
| [Team board](images/team-board.png) | Team-owned work in To Do, In Progress and Done columns |
| [Reports](images/reports.png) | Ticket status, workload and permission-scoped exports |
| [Sign in](images/sign-in.png) | Authentication screen without entered credentials |

All visible people, organizations, hostnames, IP addresses and records are synthetic. Example email/hostnames use example.invalid; displayed example IPs use the documentation range 192.0.2.0/24. The screenshot database was created separately from manual testing and contains no site or customer data.

The team-board screenshot uses a synthetic Service Desk Manager account with actual team permissions; other module views use a synthetic System Administrator account. No access controls were bypassed or disabled. The images show the real application, including the explicit demonstration banner.

Only PNG images are included. Demo databases, account passwords, session cookies, signing keys, browser profiles and capture runtime files remain local and are excluded from Git.
